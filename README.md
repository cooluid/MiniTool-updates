## 功能

- **鼠标手势**：按住右键画方向，执行后退、前进、关闭标签页等动作。不拖动直接松开，还是普通右键。
- **鼠标增强**：侧键前进/后退，单独反转滚轮方向，平滑滚动，按住 Shift 横向滚动。
- **触摸板手势**：给三指、四指的轻点和滑动设置动作。
- **窗口切换**：带缩略图，按最近使用排序，可以用拼音首字母搜索。默认 Option+Tab，也可以接管 Cmd+Tab。
- **AI 翻译**：划词 ⌥D、截图 ⌥S、输入 ⌥A。接你自己的 DeepSeek、OpenAI、通义千问、Kimi、智谱等兼容 OpenAI 接口的服务，或者本地的 Ollama。要翻译的文字直接发给你配置的服务，不经过 MiniTool。

界面有简体中文和英文。

## 安装

下载[最新版](https://github.com/cooluid/MiniTool-updates/releases/latest)的 DMG，把 MiniTool 拖进「应用程序」。需要 macOS 14 或更新版本。

MiniTool 只在菜单栏显示图标。第一次使用时，按提示在「系统设置 → 隐私与安全性」里打开辅助功能权限；窗口缩略图和截图翻译还需要屏幕录制权限。新版本可以在「设置 → 关于」里检查更新。
